## Результат этапа

| Что собрать | Что отработать |
| --- | --- |
| Консольная программа, пример CSV и журнал воспроизводимой сессии. | Денежные суммы, валидация команд, безопасная замена файла. |

## Как выглядит результат

```text
> add 2026-01-15 food 100.10
OK id=1
> add 2026-01-21 food 200.20
OK id=2
> summary 2026-01
food 300.30
TOTAL 300.30
> add 2026-01-21 food 0
ERROR amount: сумма должна быть больше нуля
> save
OK saved=2
```

## Проверка перед сдачей

- [ ] После перезапуска `load` и `summary 2026-01` возвращают тот же отчёт, следующий расход получает ID 3.
- [ ] Проверить пустой месяц, две категории, несуществующую дату и файл с плохой строкой после корректной.
